## Project Overview

**Coffee Shop Web Application** is an ordering and payment experience designed around a simple customer journey—from creating an account to completing an order. It also records sales information for later review.

### Key Features

*   **Customer Accounts**: Registration and login flows for returning customers.
*   **Product Ordering**: Browse items and add selections to a shopping cart.
*   **Cart Management**: Review and adjust an order before checkout.
*   **Payment Workflow**: Complete an order through a structured payment flow.
*   **Sales Collection**: Store transaction data for operational analysis.

### Technical Implementation

*   **Frontend**: React for interactive ordering and cart state.
*   **Design System**: Material UI for consistent, reusable interface components.
*   **Database**: MySQL for accounts, products, orders, and sales records.

### What I Learned

This project introduced me to end-to-end commerce workflows and the relationship between customer-facing interactions, application state, and persistent transaction data.
